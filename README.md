# JustUs 💞 — sirf hum dono

Ek private web app sirf do logon ke liye: **chat + voice calls + video calls**, koi server nahi, koi history save nahi hoti.

## Privacy features 🔒
- **PIN lock** — app kholne par 4-digit PIN
- **View-once photos** — ek dafa dekho, phir 🔥 jal jati hai
- **Disappearing messages** — 10s / 1m / 1h timer
- **Zero history** — refresh karo, sab gayab (messages sirf memory mein)
- **Privacy veil** — app chhupao to screen blur
- **Peer-to-peer** — calls/chat seedha dono phones ke darmiyan (WebRTC, encrypted)

## Kaise use karein
1. Dono apne phone par yehi link kholo
2. PIN banao
3. Ek **code banayega**, dusra **join** karega
4. Bas! Chat karo, 📞 voice ya 🎥 video call karo

## Tech
- Static web app (koi backend nahi)
- [PeerJS](https://peerjs.com) free cloud signaling — IDs `justus-<CODE>`
- Installable PWA (home screen par add karo)

## Imaandaar limits
- Dono ko ek waqt par online hona zaroori hai (koi message server nahi)
- Screen recording ko app rok nahi sakti — bharosa zaroori hai 💛
- PeerJS ka free server kabhi slow ho sakta hai
